# 491-Theragarden

Theragarden is a mental health and habit tracking Android application that helps users complete self-care activities while growing virtual plants.

## Features
- Habit tracking
- Plant growth system
- Mood and self-care activities
- Garden collection
- Stats and streak tracking
- Firebase login/authentication

## Technologies Used
- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Firestore

## How to Run
1. Clone the repository:
   git clone https://github.com/CodeByLess/491-Theragarden.git

2. Open the project in Android Studio

3. Allow Gradle to sync

4. Run the app using:
   - Android Emulator
   - OR a physical Android device

5. Firebase is already configured through the included google-services.json file
